# open-skills

公开的 Agent Skill 仓库。以后要开源给别人用的 Skill，都放这里。

每个 Skill 一个文件夹，文件夹里必须有 `SKILL.md`。

```text
open-skills/
  README.md
  LICENSE
  <skill-name>/
    SKILL.md
    references/
```

这是公开仓库。不要放私人笔记、密钥或未开源的项目文件。

## 已公开的 Skill

- [m-directing-stickman-videos-cn](m-directing-stickman-videos-cn/)：从话题生成中文火柴人短视频的五级架构、短文、逐段视频 Prompt 和配音。视频模型可替换，相邻视频段用上一段实际尾帧接续。
- [m-flowchart-anim](m-flowchart-anim/)：把流程或文章做成 3:4 动态流程图视频；五种风格，直角连线，BGM 卡节拍，中英文都支持。
