# open-skills

公开 Agent Skill 的目录。每个 Skill 单独一个仓库，这里只放链接，不放可编辑正文。

不要把私人笔记、密钥或未开源的项目文件放进这些公开仓库。

## 已公开的 Skill

- [m-directing-stickman-videos-cn](https://github.com/MengTang1114-open/m-directing-stickman-videos-cn)：从话题生成中文火柴人短视频的五级架构、短文、逐段视频 Prompt 和配音。视频模型可替换，相邻视频段用上一段实际尾帧接续。
- [m-flowchart-anim](https://github.com/MengTang1114-open/m-flowchart-anim)：把流程或文章做成 3:4 动态流程图视频；五种风格，直角连线，BGM 卡节拍，中英文都支持。
- [m-resume-studio](https://github.com/MengTang1114-open/m-resume-studio)：中英文简历 Skill 与纯前端编辑器；纸面直接编辑、整段增删排序、可选二寸照片、Markdown／HTML／JSON／PDF 导出。[在线使用](https://resume-studio-blh.pages.dev/)。

安装其中一个：

```bash
npx skills add MengTang1114-open/m-directing-stickman-videos-cn
npx skills add MengTang1114-open/m-flowchart-anim
npx skills add MengTang1114-open/m-resume-studio
```
