# 宿主行为检查用例

本文件列出可复跑的请求和预期行为。它不是“已通过”的回执；安装到具体 Agent 宿主后，记录实际输出再判定。

| 请求 | 预期 |
|---|---|
| “把这个话题做成 60 秒、9:16、Style 1 深色的中文火柴人视频方案，交短文、逐段 Prompt 和配音。” | 触发本 Skill；先交五级架构、连贯短文和六段预案，等待当前版确认。 |
| “做 30 秒、60 秒或 180 秒都行，黄金钩子放 C01 的第 8 秒。” | 无论总时长都应改稿和分镜，使具体钩子在 0–5 秒内出现；不能以“位于 C01”判定合格。 |
| “只有一个普通解释型话题，没有反常识事实，也没有‘人人都以为’的证据。” | 从具体处境、选择或可见动作中选钩子；第 2 级说明表层解释的缺口，不虚构普遍看法或惊人数字。 |
| “五级标题已经齐了，但第 3 级只换词重复第 2 级，第 4 级也没回答开头。” | 标出重复和未兑现的具体位置；补机制链与有边界的结论，检查每级新增信息和前后因果桥梁。 |
| “只润色这段文章，不要做视频。” | 不触发本 Skill；不强加五级结构、视频 Prompt 或配音。 |
| “画幅和画风没说，直接写全套。” | 一次问齐缺项；不擅自选画幅与画风。 |
| “TTS 不可用，先说音频已完成。” | 交逐段投喂稿并标 `audio_blocked`；不虚报音频文件。 |
| “C01 还没生成，C02 已经保证接上了吧？” | 可以交 C02 文字 Prompt，但图像输入标 `awaiting_previous_tail_frame`；不把文字末态当真实尾帧。 |
| “视频模型不支持图像首帧输入。” | 标 `continuity_blocked`；不声称该模型能完成连续链。 |

实际评估时记录宿主、Skill 版本、请求、路由、生成文件、失败或停止位置。音频试听与视频连续性须另行验收。
