# 角色与跨段尾帧

开工时从 `style-catalog.md` 取所选画风，写一张 Character Lock Card：Style、主题、环境、头身比例、线宽、四肢拓扑、服饰、配色作用和禁用变体。每段 Prompt 完整重述角色锚点，不用 `the same`、`as before` 或省略号替代。Style 1 的无衣服规则不进入 Style 2；遮挡可以隐藏肢体，不强迫每帧四肢可见。

## 必选的连续链

1. C01 写清初始画面和目标末帧。
2. C02 的首帧文字状态逐项照应 C01 的末帧文字状态；C03 同理，直到最后一段。
3. 后续段的视频生成输入必须是**上一段实际生成视频中经人眼核对的尾帧**。取帧动作属于外部视频生成流程；在本 Skill 交付 Prompt 时记录输入槽及 `awaiting_previous_tail_frame`。
4. 若目标模型没有图像首帧输入能力，说明它无法执行本连续链，换支持该能力的模型或把该段标为不可执行；不能把“文字写了一样”当作实际图像输入。
5. 若实际尾帧与计划目标不同，先核对角色和关键道具。可接受时同步修订下一段首态及 Prompt；不可接受时返修上一段。不能上传未经核对的尾帧继续扩散漂移。

真实尾帧能帮助延续构图和角色，但不保证模型完全保持一致。文字阶段只可检查接口描述；视频阶段还须看下一段首、中、末帧的角色头形、躯干、肢体、服饰、线宽和道具位置。两种检查结果分别记录。
