# 分段配音合同

只在当前五级架构、短文和分段预案获批后执行。音频必须与定稿分段稿逐字一致；不能用字数插值冒充时长。

## 生成与复用

使用当前可用且已获授权的 TTS 服务。豆包是已有案例的可选服务，不是此 Skill 的硬依赖。全片锁定同一声线、语速、音量、语气指令和输出格式；先做短试听，核对音色、专名、数字读法与停顿，再按 C01–CNN 各生成一个文件。已有音频若与当前定稿逐字一致、声线设置相同且试听合格，只读取测量，不重录。

凭证由使用者在自己的设备或宿主密钥存储中配置，可通过环境变量或项目外的本机配置文件提供。Skill、Prompt、日志、回执、示例和发布包不得包含真实 API Key、Access Token、App ID 等凭证值；不要打印这些值。开源仓库如需说明配置，只列变量名和空占位示例，不附本机凭证文件。配置不可用时按 `audio_blocked` 处理。

对每段记录：段号、定稿文本、服务或声线标识、文件路径、格式、总时长 T、校验值、试听结论。密钥、账号和接口地址不得写入交付文档。TTS 不可用、费用或外发权限未获授权时，只交逐段 `tts-input.txt` 并标 `audio_blocked`；不可声称音频已完成。

## 约 10 秒时间桶

每段目标 D 约 10 秒，实际视频模型输出时长以后续实片为准。若 T 小于目标 D，配音文件保持原样，规划中只允许段尾静音；不在句内或句间插静音，不变速，不截字。若 T 超过 D，先改短文或重新切段，再让用户确认受影响版本并重新合成该段。句级时码来自试听或波形标注，未核定时写“待试听核定”。

本 Skill 交付音频文件及测量表；不执行视频剪辑、音画同步验收或字幕制作。配音总时长相近只证明时长可安排，不证明生成画面动作已经对齐。
