# 三拍画面语义检查

这是从真实回片问题提炼的通用检查，在把分镜写成每段视频 Prompt 时使用。它约束画面**表达什么**，不把某一条影片的道具、配色或剧情写成通则。

1. 对每拍列出“口播意思 → 观众应看见的对象、关系或变化 → 具体动作”。新出现的图形要能指向该拍的词或关系；说不清作用的装饰删掉。
2. 具名事物用可辨认轮廓表达。抽象圆点、空白矩形或装饰线不能默认代表糖、书、成绩、人物关系等具体概念。精确数字若不画在画面里，由配音承担，但关系仍要可见。
3. 画面要保持口播的施受关系、方向和立场。否定命题须有可见的否定、移除或被拒动作；不能用正向取得来演“不是”。不把受压者演成赢家，也不让责任箭头指错对象。
4. 同一颜色或图标跨段保持同一语义。度量箭头、线或落差要有明确的两端对象，不把一段的测量标记随意拉成下一段的背景装饰。
5. 在不看字幕和配音的条件下，读三拍分镜：能否大致复述关键对象与关系。文字阶段只能做这个**设计检查**；真实观众是否看懂，仍须等视频回片后验证，不得提前声称通过。
