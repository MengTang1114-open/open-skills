# 中文火柴人短视频导演

## 任务与边界

把一个话题或一份素材依次变成：**五级叙事架构 → 可口播的中文短文 → 每段约 10 秒的分镜与独立视频 Prompt → 与定稿短文逐段一致的配音音频**。视频生成模型可替换；本 Skill 不负责生成视频、抽帧、剪辑、字幕、BGM 或成片验收。不要把只写出 TTS 投喂稿称为“已交付配音”。

中文短文、独立音频和模型无关的视频 Prompt 是本 Skill 的交付边界。它可以独立使用，不要求安装其他 Skill。具体模型、账号、接口与剪辑软件不进入此合同。

## 输入与开工门

- 必填：话题或源素材；画幅 `16:9` / `9:16`；画风（Style 1 浅色/深色，Style 2A 或 Style 2B）。缺项一次问全，不擅自选画幅或画风。
- 时长可选，默认 60 秒；以约 10 秒为一段。用户给非 10 的倍数时取最近倍数，正中间向上取，最少 10 秒，并告知折算结果。
- 配音声线、语速、音频格式和视频生成模型可选。已有可用设置沿用；视频模型未指定时写通用 Prompt，不默认指定 Gemini。配音服务若未指定，先核查当前可用且已授权的 TTS；不可用时停在音频步骤，交已完成稿件并明确缺口。
- 用户提供的事实、数字、引语和专名要核对来源；来源不清时保留为待核，不编造成确定事实。外部补充事实须经用户许可且可核验。

## 流程

1. 读 `references/storyboard-template.md` 和 `references/style-catalog.md`。先定一个核心主张，再列五级叙事架构：黄金钩子、打破常识、拉出内幕、真相揭秘、升华互动。逐级写明要回答的问题、核心句、依据、段号和留给下一级的问题，并按模板检查钩子形式、原解释缺口、机制链、结论边界和观众用途；不为凑五级捏造事实。**不论总时长，黄金钩子必须在开头 5 秒内出现**，不能只笼统放在 C01。
2. 按五级架构写一篇连贯、可直接朗读的**中文短文**，再切成 N 段约 10 秒口播。短文是文字真源；分段稿必须逐字取自短文，不能在分镜、TTS 和 Prompt 之间偷偷换词。给每段三拍视觉设计和相邻首尾状态。连续节选要标成节选，不冒充完整五级。
3. 交五级架构、短文和分段预案，等待用户明确批准当前版本。改短文、段数、画幅、画风或场景结构，重出受影响预案并重新确认；旧版批准不自动沿用。
4. 批准后读 `references/voiceover.md`，使用可用且已授权的 TTS 按段生成配音，试听读音与停顿，测每个文件的实际时长 T。已有音频与定稿逐字一致且声线一致时直接复用。T 超出该段目标时长时，修改短文或分段并重新确认，不截字或强行变速。无法生成音频时交分段投喂稿与状态，不写“配音完成”。
5. 读 `references/character-lock.md`、`references/visual-semantics.md` 和 `references/video-prompt-contract.md`，写 N 份独立、可复制的视频 Prompt。每份包含完整角色锁、实际配音对应的三拍语义、首帧状态和末帧状态。模型参数只在适配字段填写；没有指定模型时保持通用，不宣称任何模型保证 10 秒、无声或精确角色复现。
6. **逐段接帧**：第 i 段 Prompt 的末帧文字状态，要在第 i+1 段写成相同的首帧文字状态；第 i+1 段的实际图像输入明确指定为“第 i 段实际生成视频的已验收尾帧”。一段的 Prompt 末帧描述不等于真实尾帧图。此 Skill 可先交齐全部 Prompt，但第 2 段起标记 `awaiting_previous_tail_frame`，直到外部生成者提供上一段真实尾帧；若生成结果与计划末态不符，修订相邻 Prompt 或返修该段，不能用不匹配画面硬接。
7. 按 `references/checks.md` 检查文字、音频和 Prompt。只报告实际完成的层级，不把 Prompt 齐全说成视频已生成或连续性已通过。

## 交付与验收

- `01-五级架构.md`：五级要点、事实边界和目标时长。
- `02-短文与分段.md`：完整中文短文、C01–CNN 逐字分段、每段三拍、首末帧文字状态。
- `03-配音/`：C01–CNN 音频文件及 `manifest.csv`（段号、逐字口播、声线、T、文件名、校验值、试听状态）。音频缺失时只交 `tts-input.txt` 并标 `audio_blocked`。
- `04-视频Prompts/`：C01–CNN 各一份独立 Prompt；每份注明目标约 10 秒、适配字段、首帧来源、末帧目标，以及 `prompt_complete` 或 `awaiting_previous_tail_frame`。另交相邻接口表。

通过条件：五级架构与短文同一论点；黄金钩子在 C01 的 0–5 秒有明确口播或画面动作，口播落点经实际音频试听；分段连回短文无增删改；N 与目标时长相符；每段音频实际存在且试听、时长记录可回读；Prompt 的三拍与该段口播相符；每对相邻段的文字尾态/首态相同，且下一段明确要求使用上一段**实际**尾帧。若缺音频或真实尾帧，分别标明，不能报全链路通过。

## 停止条件

缺必填规格或事实冲突时停在架构前；未批准当前预案时停在音频与 Prompt 前。TTS 工具、凭证、费用或外发权限缺失时只停音频动作并交可用文字，不擅自调用付费服务。上一段真实尾帧缺失或不合格时，后续 Prompt 可交草案，后续视频输入保持待绑定，不声称角色或画面连续已验证。用户若要直接生成视频或剪辑成片，另走相应能力和授权。
