# 凭证与隐私

本仓库只发布 Skill 文本、参考规则和公开包检查脚本。不要提交真实 API Key、Access Token、App ID、服务账户文件、TTS 请求日志、用户原稿、生成音频或视频。

使用 TTS 时，在本机环境变量、操作系统密钥存储或项目外且受权限保护的文件中配置凭证。公开文档只能列变量名和空占位，不得复制真实值。若误将凭证提交到公开仓库，应立即在服务提供方撤销或轮换该凭证；删除当前文件不足以清除 Git 历史。

提交前运行 `python3 tools/check_public_bundle.py`，并另外检查最终待提交文件及 Git 历史。此脚本是针对本目录的基础防漏检查，不保证发现所有秘密。
